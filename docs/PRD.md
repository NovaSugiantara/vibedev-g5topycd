# Product Requirements Document

# Product

Yarn Stash Yardage Calculator

---

# Problem

Knitters and crocheters often own multiple yarn skeins but are unsure whether the combined yardage is enough for a project.

Users currently calculate totals manually.

The application should instantly answer one question:

"Do I have enough yarn?"

---

# Goal

Provide a fast calculator that combines multiple yarn skeins and compares them against a required project yardage.

The experience should require almost no learning.

---

# Target Users

- Knitters
- Crocheters
- Hobby makers

---

# User Flow

Open page

↓

Add yarn skein

↓

Add another skein (optional)

↓

Enter required project yardage

↓

Instant result

↓

Edit or remove skeins anytime

---

# Success Criteria

Users can determine within seconds whether they have enough yarn.

No page reloads.

No backend.

No login.

Everything updates instantly.
