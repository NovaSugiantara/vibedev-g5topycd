# Hallmark Design Skill

The application must avoid generic AI generated interfaces.

Every visual decision should communicate intention.

---

# Design Principles

Prioritize

Clarity

Hierarchy

Whitespace

Balance

Consistency

Motion

Accessibility

---

# Layout

Single centered card

Large breathing room

Clear sections

Comfortable spacing

Maximum width around 700px

---

# Typography

Clear visual hierarchy

Large numbers

Readable labels

Consistent font scale

---

# Colors

Neutral interface

Green

Enough yarn

Yellow

Almost enough

Red

Need more yarn

Never rely only on color.

Always pair with text.

---

# Components

Cards

Rounded corners

Subtle shadows

Comfortable padding

Buttons should have obvious hover and focus states.

---

# Inputs

Simple

Readable

Consistent sizing

Inline editing should feel seamless.

---

# Motion

Fast

Subtle

150–250ms

No distracting animation.

---

# Responsive

Designed mobile first.

Should also look natural on desktop.

No horizontal scrolling.

---

# Empty State

When there are no yarn entries

Display a friendly prompt encouraging users to add their first skein.

---

# Hallmark Checklist

Before shipping verify

✓ Strong visual hierarchy

✓ Consistent spacing

✓ Good alignment

✓ Obvious interaction

✓ Responsive

✓ Accessible

✓ No unnecessary decoration

✓ No "AI slop" appearance
